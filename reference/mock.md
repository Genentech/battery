# function create single mock for shiny function

function create single mock for shiny function

## Usage

``` r
mock(name, mock, env, package = "shiny")
```

## Arguments

- name:

  \- string with name of the function

- mock:

  \- function used as mock for name in package

- env:

  \- additional environment that is also updated

- package:

  \- name of the package
