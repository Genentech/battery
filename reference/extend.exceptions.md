# helper function that extend existing exception handler note that if same handler function is used it will be overwritten

helper function that extend existing exception handler note that if same
handler function is used it will be overwritten

## Usage

``` r
extend.exceptions(handler, session = NULL)
```

## Arguments

- handler:

  \- named list of exception handlers

- session:

  \- optional shiny session, if omitted the global handlers are extended
